# Bike Store Sales Analysis

## Overview
This repository contains an analysis of bike store sales data, focusing on customer demographics, product performance, profitability, and regional trends. The analysis includes data cleaning, exploration, and dashboard creation to provide actionable insights.

## Project Highlights
- **Data Cleaning:** Handled missing values and inconsistencies for accuracy.
- **Data Analysis:** Explored sales trends, customer demographics, and product categories.
- **Dashboard Creation:** Developed a dashboard summarizing key sales metrics.

## Tools Used
- **Microsoft Excel**: For data manipulation, visualization, and dashboard development.

## Key Insights
1. **Customer Demographics**:
   - Majority of customers are Middle Aged (35-64 years), contributing the highest revenue.
   - Gender distribution shows significant sales from both Male and Female customers.
2. **Product Categories**:
   - **Road Bikes** generate the highest revenue, followed by Mountain Bikes and Helmets.
   - Accessories like Bike Racks also contribute to profitability.
3. **Regional Performance**:
   - California leads in sales, followed by England and British Columbia.
4. **Profitability**:
   - Consistent profit growth from 2011 to 2013, with the highest profits recorded in 2013.
5. **Revenue by Shipping**:
   - Analysis reveals trends in shipping classes and their revenue impact.

## Dashboard Features
- Visual representation of revenue, profit, and product performance.
- Interactive filters for customer age group and product categories.
- Year-over-year analysis of sales and profitability.
